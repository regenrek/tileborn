# AI Specification

## Model Boundaries

No AI model is required for the Battle Royale Creator Vertical 1.0. Core game
authoring, validation, recovery, playtest and shipping must remain deterministic
and fully usable offline.

## Prompt Contracts

Not applicable. A future optional assistant may consume public authoring schemas
through explicit commands, but it may not bypass validation or write project
files outside canonical services.

## Evaluation

Not applicable to the release oracle. Automated and live product verification,
not model judgment, determines completion.
