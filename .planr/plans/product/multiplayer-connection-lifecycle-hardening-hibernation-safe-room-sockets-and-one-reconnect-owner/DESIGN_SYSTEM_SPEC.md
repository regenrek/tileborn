# Design System

## Principles

Connection state is calm, explicit, and actionable. Expected reconnect is not
presented as a fatal crash.

## Components

Reuse existing lobby, toast/error, HUD, and results components. Add no parallel
network settings surface.

## Accessibility

Reconnect/error announcements use existing accessible status semantics; Retry
and Leave remain keyboard reachable with visible focus and reduced-motion
behavior.
