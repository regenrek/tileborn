# Analytics Observability

## Events

- Existing local session/match/gameplay events are sufficient; no product analytics required.

## Diagnostics

- Existing debug surfaces may expose session phase, tick/frozen state, resolved capability,
  local input sequence, authoritative position, spawn-safety conflicts, and accepted events.
- Diagnostics must be local, bounded, and removable from normal play presentation.

## Privacy

No raw long-term input history, credentials, or personal data is collected.
