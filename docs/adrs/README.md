Numbering note: ADR-0018 is now allocated to the neutral combat simulation (this index). ADR-0019 is allocated to the game-object catalog. Because ADR-0020/0021/0022 were allocated to Tiled interop, pack capability, and the game-menu framework, the remaining ADR-0017 parity follow-ups are reconciled to ADR-0023–0028 (see ADR-0017 "Follow-up ADR numbering reconciliation"). ADR-0023 and ADR-0024 are now written (Proposed): ADR-0023 scopes the **non-BR game-mode contracts** portion of its slot (settings + mode discovery + pickup/equippable); the runtime-map-package + authoring-to-playtest capstone sibling is now written as ADR-0030; ADR-0024 scopes the **gameplay input + keybinds** portion of its slot; the HUD-widgets sibling it left open is now covered by ADR-0027, and the neutral gameplay-event-stream contract by ADR-0029. ADR-0026 scopes the first-class Visual Role Editor and Player Model Editor workbench. ADR-0027 scopes the HUD framework (layout-as-data + shared chassis).

Boundary note: `tileborne` owns the OSS editor, runtime, plugin API, neutral engine primitives, and `packages/plugin-battle-royale`; `packages/plugin-battle-royale` owns Battle Royale plugin gameplay logic; `petwars-product` consumes those outputs for private branding, assets, maps, deploy, and product config.
